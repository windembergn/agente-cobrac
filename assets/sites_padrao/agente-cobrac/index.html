// Limites

Copiloto — nunca substituto

Organizo, transcrevo e redijo. Diagnóstico, conduta e assinatura continuam sempre com o cirurgião. Todo documento sai marcado como minuta para revisão. Autorização de convênio não é confirmada por mim — só o pedido é redigido para a operadora avaliar.

// Dúvidas

Perguntas frequentes

Preciso instalar algum aplicativo?

Não. Tudo roda no mesmo WhatsApp do consultório — áudio, foto, PDF ou texto, e a resposta chega ali mesmo.

O agente decide o tratamento do paciente?

Nunca. Toda decisão clínica é do cirurgião. O que é entregue sempre chega marcado como minuta para revisão e assinatura.

Como funciona a liberação no convênio?

Você passa os dados do caso e o relatório sai no formato que a operadora espera, com CID e TUSS quando informados. Dado que falta fica sinalizado "a confirmar" — nunca inventado.

Como funcionam os lembretes automáticos?

Você define uma vez o que precisa ser lembrado e quando; a partir daí o envio acontece sozinho, com aviso se algo sair do esperado.

Dá para publicar uma página para o paciente?

Sim — direto no domínio do consultório, com link pronto para mandar no WhatsApp.

Meus dados e os dos pacientes ficam seguros?

Ficam no ambiente do próprio consultório, sem compartilhamento com terceiros.
